# lib_json

`p101_json` provides bounded JSON parsing, token access, and JSON string
encoding. It reports parse and capacity failures through `p101_error` and owns
no tool-specific schema or policy.

## Example

[`lib_json_examples`](https://github.com/programming101dev/lib_json_examples)
contains the executable examples for this library, including parsing an object
and looking up a string value.
